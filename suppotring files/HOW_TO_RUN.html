🧠 AI File Intelligence Bot

Follow these steps to launch your RAG-powered document chatbot

1
Open Command Prompt
Press Win + R, type cmd, then press Enter.
A black terminal window will open.
🖥️
↓
2
First time only
Install Python dependencies
Copy and paste this into CMD, then press Enter. Wait for it to finish (2–5 min).
py -m pip install fastapi uvicorn python-multipart chromadb scikit-learn python-docx pymupdf langdetect python-dotenv aiofiles
You only need to do this once. Skip it next time.  |  If py fails try python -m pip install ...
📦
↓
3
Every time
Navigate to the backend folder
Copy and paste this into CMD, then press Enter.
cd "C:\Users\user\Documents\Claude\Projects\🧠 AI FILE INTELLIGENCE BOT (RAG + OCR + React + Python)\backend"
📁
↓
4
Every time
Start the server
Type this and press Enter:
python main.py
INFO:    Uvicorn running on http://0.0.0.0:8000
INFO:    Application startup complete.
If you see the above — the server is running! ✅
🚀
↓
5
Open the app in your browser
Click the link below or paste it into your browser:
http://localhost:8000

Upload a document → Ask a question → Get AI-powered answers
🌐
⚠️

Keep the CMD window open the entire time you use the app.
Closing it will stop the server and the app will stop working.

+
Optional upgrade
Add OpenAI API key for smarter answers
Without a key, the bot shows retrieved document chunks.
With a key, it gives you full GPT-synthesized answers.
# Open the .env file in the project root and add: OPENAI_API_KEY=sk-your-key-here
File location: 🧠 AI FILE INTELLIGENCE BOT (RAG + OCR + React + Python)\.env
